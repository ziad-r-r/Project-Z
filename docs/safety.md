# قواعد الأمان — Project Z

## تحذير هام

إعطاء ذكاء اصطناعي صلاحيات كاملة على جهازك يعني إنه يقدر:
- يحذف ملفات
- يثبت برامج
- يعدل إعدادات النظام
- يرسل بيانات (لو في إنترنت)

**استخدم Full Control Mode فقط لو أنت فاهم المخاطر.**

---

## مستويات الصلاحيات

### 1. Safe Mode (الافتراضي)
- يقرأ الملفات والمجلدات بحرية
- يطلب تأكيد قبل أي كتابة أو أمر shell
- ممنوع حذف أو تثبيت بدون موافقة صريحة

### 2. Trusted Mode
- يسمح بأوامر معينة بدون تأكيد (مثل `npm install`, `git commit`)
- لسه بيمنع الأوامر الخطيرة جداً (`rm -rf`, format, إلخ)

### 3. Full Control Mode
- تحكم كامل
- يجب تفعيله يدوياً من الواجهة
- يظهر تحذير كبير أول مرة
- كل الأوامر لسه مسجلة في الـ Log

---

## Kill Switch

في الواجهة الرسمية فيه زر **إيقاف فوري** يوقف الـ Agent في نفس اللحظة.

---

## توصيات

- اعمل Backup قبل ما تدي صلاحيات عالية
- راجع الـ Activity Log بانتظام

# Project Z

**ذكاء اصطناعي محلي خاص — يبني تطبيقات ومواقع من البرومبت فقط + صلاحيات تحكم كاملة في الجهاز**

> Local Private AI Agent that builds full applications & websites from natural language prompts, with optional full system control.

---

## الرؤية (Vision)

Project Z هو نظام ذكاء اصطناعي محلي (Local-First) يعمل على جهازك بالكامل:

- يفهم البرومبت بالعربي أو الإنجليزي
- يبني مشاريع ويب وتطبيقات كاملة (Frontend + Backend)
- يقدر يتحكم في الجهاز (ملفات، تيرمينال، متصفح، برامج) بإذنك
- واجهة رسمية (Dashboard) جميلة وسهلة
- خصوصية 100% — الكود والموديل على جهازك

---

## الميزات الرئيسية

| الميزة | الوصف |
|--------|--------|
| **بناء مشاريع كاملة** | من برومبت واحد → مشروع Next.js / React / Flutter / Django جاهز |
| **تحكم كامل في الجهاز** | تشغيل أوامر، تعديل ملفات، فتح برامج، تصفح الويب (مثل Open Interpreter) |
| **واجهة رسمية** | Dashboard ويب محلية مع محادثة + سجل المهام + إدارة المشاريع |
| **موديلات محلية** | يعمل مع Ollama (Qwen2.5-Coder, DeepSeek-Coder, Llama 3.1...) |
| **خصوصية تامة** | لا يرسل أي كود أو بيانات لسيرفر خارجي |
| **عربي أولاً** | دعم RTL وفهم اللهجة المصرية |

## البدء السريع (Quick Start)

### 1. المتطلبات
- جهاز بـ GPU قوي يفضل (16GB+ VRAM) أو على الأقل 16GB RAM
- Python 3.11+
- Node.js 20+
- Ollama مثبت

### 2. تثبيت الموديل
```bash
ollama pull qwen2.5-coder:32b
# أو
ollama pull deepseek-coder-v2
```

### 3. تشغيل الـ Agent (قريباً)
سيتم إضافة أوامر التثبيت الكاملة في الإصدارات القادمة.

## الأمان مهم جداً ⚠️

إعطاء أي ذكاء اصطناعي **صلاحيات تحكم كاملة في الجهاز** خطر.

Project Z مصمم بـ:
- تأكيد يدوي قبل أي أمر خطير (حذف ملفات، تثبيت برامج، تعديل نظام)
- وضع Safe Mode افتراضي
- سجل كامل لكل الأوامر
- إمكانية إيقاف فوري

اقرأ ملف `docs/safety.md` قبل التفعيل.
